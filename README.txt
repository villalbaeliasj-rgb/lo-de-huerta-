LO DE HUERTA — PWA V1.1

PUBLICAR GRATIS CON GITHUB PAGES
1. Iniciá sesión en GitHub y creá un repositorio nuevo llamado lo-de-huerta.
2. Subí TODOS los archivos y carpetas de este paquete a la raíz (index.html debe quedar en la raíz).
3. Abrí Settings > Pages.
4. En Build and deployment elegí Deploy from a branch, rama main y carpeta /(root). Guardá.
5. Cuando se publique, abrí la URL que muestra GitHub Pages desde Chrome en tu Motorola.
6. En Chrome tocá ⋮ y elegí Instalar aplicación o Añadir a pantalla principal.

La primera carga requiere internet. Luego el service worker guarda los archivos para abrir la calculadora sin conexión. La publicación requiere que vos inicies sesión y confirmes los pasos en tu cuenta; no compartas contraseñas ni códigos.
